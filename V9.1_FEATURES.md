## ⚡ 1. Flash Sales Service

### Какво прави?

Управление на временни промоции, който създават urgency и увеличават traffic.

### Основни функции:

#### A) Flash Sales
Ограничени по време или количество промоции

```javascript
// Създаване на Flash Sale
const flashSale = flashSalesService.createFlashSale({
    name: '2-часов МЕГА Sale!',
    productIds: [15, 22, 38],
    discountType: 'percentage',
    discountValue: 40,
    startTime: new Date('2025-11-20 18:00'),
    endTime: new Date('2025-11-20 20:00'),
    maxQuantity: 50,          // само 50 бройки общо
    maxPerCustomer: 3,        // до 3 на клиент
    showCountdown: true,      // countdown timer
    showStockLeft: true       // "Остават 15 бройки!"
});

// Проверка дали продукт е във flash sale
const flashInfo = flashSalesService.getActiveFlashSaleForProduct(productId);
if (flashInfo) {
    console.log(`Flash Price: ${flashInfo.pricing.flashPrice} лв`);
    console.log(`Време до края: ${flashInfo.timeLeft.displayText}`);
    console.log(`Остават: ${flashInfo.quantityLeft} бройки`);
}
```

**Резултат:**
```
Flash Price: 8.99 лв (вместо 14.99 лв)
Време до края: 1ч 23м
Остават: 15 бройки
```

#### B) Happy Hours
Различни цени по часове на деня

```javascript
// Happy Hour от 14:00 до 16:00 всеки ден
const happyHour = flashSalesService.createHappyHour({
    name: 'Следобедна щастлива цена',
    productIds: [5, 8, 12, 15], // или 'all' за всички
    discountPercent: 20,
    daysOfWeek: [0, 1, 2, 3, 4, 5, 6], // всеки ден
    startHour: 14,
    endHour: 16,
    validFrom: new Date(),
    validUntil: new Date('2025-12-31')
});

// Автоматична проверка
const happyHourInfo = flashSalesService.getActiveHappyHourForProduct(productId);
if (happyHourInfo) {
    console.log(`Happy Hour цена: ${happyHourInfo.discountedPrice} лв`);
    console.log(`Приключва след: ${happyHourInfo.endsInHours}ч`);
}
```

**Use cases:**
- ☕ Morning coffee discount (7:00-9:00)
- 🍞 Afternoon bakery sale (14:00-16:00)
- 🌙 Evening clearance (20:00-22:00)

#### C) Daily Deals
Продукт на деня с специална цена

```javascript
// Продукт на деня
const dailyDeal = flashSalesService.createDailyDeal({
    productId: 42,
    discountPercent: 30,
    date: new Date('2025-11-20'),
    maxQuantity: 100
});

// Check днешния deal
const todaysDeal = flashSalesService.getTodaysDailyDeal();
if (todaysDeal) {
    console.log(`
        Продукт на деня: ${todaysDeal.productName}
        Deal цена: ${todaysDeal.dealPrice} лв
        Обикновена цена: ${todaysDeal.originalPrice} лв
        Спестявате: ${todaysDeal.savings} лв (${todaysDeal.discountPercent}%)
        Продадени: ${todaysDeal.soldQuantity}/${todaysDeal.maxQuantity}
    `);
}
```

## 🎪 2. Loss Leader Service

### Какво прави?

Стратегическо ценообразуване - продаваме евтини "магнит" продукти, за да привлечем клиенти които купуват високомаржинални items.

### Концепция:

```
Евтин хляб (загуба 0.50 лв)
    ↓
Клиентът влиза в магазина
    ↓
Купува и масло + сирене + кафе (печалба 4 лв)
    ↓
NET PROFIT: +3.50 лв
```

### Основни функции:

#### A) Auto-Discovery на Loss Leader Opportunities

AI намира най-добрите кандидати:

```javascript
// Автоматично откриване
const opportunities = lossLeaderService.discoverLossLeaderOpportunities();

// Example output:
[
    {
        product: { name: 'Хляб 500g', price: 1.50, cost: 1.10 },
        currentMargin: '26.7%',
        proposedPrice: 1.05,    // под себестойност!
        lossPerUnit: 0.05,
        frequency: 450,         // купуван 450 пъти
        topPairings: [
            { name: 'Масло', margin: 35%, avgRevenue: 3.20 },
            { name: 'Сирене', margin: 40%, avgRevenue: 2.80 },
            { name: 'Кафе', margin: 45%, avgRevenue: 4.50 }
        ],
        avgPairingRevenue: 10.50,
        estimatedNetProfit: 10.45,  // 10.50 - 0.05
        roi: '20900%'  // MASSIVE ROI!
    }
]
```

#### B) Създаване на Loss Leader

```javascript
// Създаване на loss leader
const lossLeader = lossLeaderService.createLossLeader({
    productId: 5,           // хляб
    lossLeaderPrice: 1.05,  // под себестойност (cost: 1.10)
    targetPairings: [8, 12, 15], // масло, сирене, кафе
    validFrom: new Date(),
    validUntil: new Date('2025-12-31'),
    goal: 'basket_size'
});

console.log(`
    Loss Leader: ${lossLeader.productName}
    Оригинална цена: ${lossLeader.originalPrice} лв
    Loss Leader цена: ${lossLeader.lossLeaderPrice} лв
    Загуба на единица: ${lossLeader.lossPerUnit} лв
    Target pairings: ${lossLeader.targetPairings.length}
`);
```

#### C) Pairing Recommendations

Real-time препоръки на касата:

```javascript

// Покажи на касиера:

```

## 💡 Best Practices

### Flash Sales:
1. Не прекалявайте - max 2-3 flash sales седмично
2. Happy hours за slow periods (не peak hours)
3. Clear countdown timers създават urgency
4. Комбинирайте с social media announcements

### Loss Leaders:
1. Избирайте високочестотни продукти (хляб, мляко)
2. Monitor pairing rate постоянно
3. Visual merchandising - pairings до loss leader
4. Test различни pairing combinations

### Seasonal Campaigns:
1. Планирайте 2-3 седмици предварително
2. Auto-create campaigns в началото на годината
3. Use year-over-year data за improvement
4. Bundle seasonal products aggressively
